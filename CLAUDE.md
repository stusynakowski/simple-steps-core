# simple-steps-core

The engine of the Simple Steps app (separate repo, `Simple_Steps`). A redesign
is in progress on branch `core-handover`: read [docs/design/](docs/design/)
before changing code. The object model and its words are in
[docs/design/object-model.md](docs/design/object-model.md); the order of work
is in [docs/design/cleanup-plan.md](docs/design/cleanup-plan.md).

`core-handover/` is generated by the app repo (`scripts/core_handover.py`) as
input for this work. Read it; don't edit it.

## Rules

- The grid model is the only model. Anything else is moved onto it or removed.
- Verify a claim by running it, never by reading docs.
- No mutable state at module level: everything a workflow uses hangs off its
  kernel.
- An empty step is a 1×1 frame with one cell `"empty"`, never a placeholder.
- Extras live under a namespace and are never hashed.
- Restructuring keeps the tests green. Each behaviour change is confirmed with
  the owner, in small pieces, before it lands.
- Use the words in object-model.md §1, and none of the retired ones.

## Commands

```bash
.venv/bin/python -m pytest                            # the tests
STRESS=1 .venv/bin/python -m pytest tests/unit/test_reshape_properties.py   # the property test, 2,000 examples
.venv/bin/python examples/all_orchestrations/pipeline.py
.venv/bin/python examples/kernel_session.py            # the working guide's session
.venv/bin/python scripts/core_asks.py                  # one probe per ask: OPEN / DONE
```
