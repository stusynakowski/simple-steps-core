# What we are building

> Branch `core-handover`. Reorganised 2026-11-03: one model, one plan, one
> decisions log. The inputs the design was drawn from are in
> [`core-handover/`](../../core-handover/) (generated by the Simple Steps
> repo, read-only).

`simple-steps-core` is the engine of Simple Steps: the part that knows what a
workflow is and how it runs. **Everything the app can do to a workflow can be
done to a `Kernel` in a plain Python session**, with only core installed.

## Rules for working on core

1. **One model.** The grid model is the only model. Anything else is moved
   onto it or removed.
2. **Verify by running.** A claim about behaviour is checked by running core,
   never by reading docs (these included).
3. **No mutable state at module level.** Everything a workflow uses hangs off
   its kernel.
4. **An empty step** is a 1×1 frame with one cell `"empty"`, never a
   placeholder.
5. **Extras live under a namespace and are never hashed.**
6. **Behaviour changes land in small, confirmed pieces.** A restructure that
   changes no behaviour keeps the tests green. A change in behaviour is
   confirmed by the owner before it lands.
7. **One word, one meaning,** as defined in [model.md §2](model.md#2-the-words).
